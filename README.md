  <h1 align="center">
  RandPicker
</h1>
<p align="center">
 新一代智能选人工具
</p>

Windows 构建会由 GitHub Actions 自动打包，发布版本可在 [Releases](https://github.com/windyslime/RandPicker2/releases) 下载。ClassIsland v2 联动插件源码和 `.cipx` 发布包位于 [windyslime/RandPicker_CI](https://github.com/windyslime/RandPicker_CI)。

当前版本支持从 ClassIsland 读取当前科目，并按科目隔离抽选记忆；记忆历史可在设置中选择是否保存到本地。
